# 정전 병동 배전

오프라인에서 `index.html`을 열면 실행되는 12턴 한국어 배전 게임입니다. 설치·서버·계정·네트워크가 필요 없습니다. **완전히 가상의 병동·설비·추상 수치를 사용하는 게임이며 실제 의료·안전 조언이나 환자 영향 모델이 아닙니다.**

## 게임 규칙

- 병동 네 곳에 각각 정수 전력 0–3을 배분합니다. 병동 카드의 필수량 이상이면 해당 시간의 미달이 없습니다.
- 12시간 동안 발전량은 시간별 고정 3–4, 배터리 최대 12입니다. 할당 합계가 발전량+현재 배터리보다 크면 진행할 수 없습니다.
- 진행하면 발전량을 우선 쓰고 부족분만 배터리에서 방전합니다. 남는 발전량은 최대 2, 배터리 빈자리 이내로 충전합니다. 수요 미달 1단위당 3점, 같은 병동 3시간 이상 연속 미달이면 시간마다 추가 2점 감점됩니다. 시작 100점, 45점 이상으로 마치면 성공입니다. 점수는 0 아래로 내려가지 않습니다.
- 여섯 가상 설비(신호등·기록판·온도고리·빛기둥·전달관·정화탑)가 네 병동 카드에 표시됩니다. 고정 기본 수요 패턴에 12개 사건 카드가 한 장씩 적용됩니다. 화면은 현재 사건과 **다음 시간의 사건·수요**를 예고합니다. 사건은 발전량이나 이미 확정한 시간을 변경하지 않습니다.
- `−/+`, 슬라이더 또는 키보드 `1`–`4`로 병동 선택 후 `←/→`로 배분합니다. `U`는 **현재 시간의 마지막 배분 한 번**을 되돌리고, `Enter`는 시간을 진행합니다. 터치도 버튼·슬라이더로 가능합니다. 확정한 시간은 되돌릴 수 없습니다.
- 새 게임의 정수 시드를 바꾸면 사건 순서가 달라집니다. 동일 시드는 동일 순서입니다. 자동 저장은 브라우저 `localStorage`에만 있고, 다른 브라우저나 시크릿 창으로 이동하지 않습니다. 결과 화면에서 같은 시드 또는 새 시드로 다시 시작할 수 있습니다.

## 검증

`node tests/run.cjs` — 사건/설비 수, 시드 결정성, 할당 경계, 예산 차단, 여러 시드와 0·1·11·12 잔량의 모든 0–3 배분 조합에 대한 보존식·상하한, 경고/연속 미달, 되돌리기, 12턴 종료, 저장 데이터 검증, 성공 가능한 배분 전략. 브라우저 개발자 콘솔에서 `fetch('tests/ui-check.js').then(r=>r.text()).then(eval)`을 실행하면 시작·조작·저장·결과·재시작·화면 가로 넘침을 검사합니다. 로컬 파일로 열 때는 개발자 콘솔에서 해당 파일 내용을 붙여 넣거나 임시 정적 서버에서 검사할 수 있습니다.
